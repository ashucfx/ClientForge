# Catalyst ClientForge

Enterprise invoicing, client management, and service operations platform for Catalyst.

## Overview

Catalyst ClientForge is a private operational system that centralizes client onboarding, global invoicing, collaborative deliverable workflows, and engagement management.

## Key Capabilities

- **Invoicing & Payments**: Multi-currency invoicing with automated payment reconciliation.
- **Client Operations Portal**: Deliverable tracking, intake forms, draft review, and scope management.
- **Admin Management**: Role-based access control, session audit logs, and delivery tracking.

## Technical Foundation

- **Platform**: Next.js (TypeScript)
- **Data**: PostgreSQL with Prisma ORM
- **Design**: Catalyst Design System
